Session 1 - M3 Setup and Administration

Order Types, Fields, and Payment Setup

1.5 hours
Objective

Read the prepay switches on Adleta's payment terms.

Scenario

Before go-live, confirm which payment terms make orders wait for payment. Read-only: change nothing.

Practice Tasks
1. Open payment terms
  1. Press Ctrl+R, type CRS075, and click OK. Company 100.
  2. For PCD, CSH, CC, DUR, COD, CSD, and PP, note Cash payment, Calculate COD, and Payment proposal.
2. Compare to Mike's table
  1. PCD and CSH should show 2 / 1 / 1. COD, CSD, and PP should show 0 / 0 / 0.
  2. Note any difference.
3. Check the cash desks
  1. Press Ctrl+R, type OIS210, and click OK.
  2. List the desks (expected 101A and 101B). Open OIS211 and OIS212 for each and note payment methods and users.
Expected Outcomes
  • Switches recorded for every pay-first-related term.
  • Cash desk methods and users recorded.
  • Differences sent to Mike.
Sign-Off Checklist
  • I know what OIS010 and OIS014 control
  • I can read the prepay switches in CRS075
  • I know how cash desks are set up
  • I test setup changes in company 100 first
Knowledge Check
1. Order type behavior (credit check, panels) is in:
  • OIS010 (correct)
  • OIS100
  • CRS610
  • MWS410
2. Which switches make a term pay-first?
  • Cash payment, Calculate COD, Payment proposal (CRS075) (correct)
  • Credit limit
  • Route
  • Item status
3. Users are connected to a cash desk in:
  • OIS212 (correct)
  • OIS215
  • MNS150 only
  • ARS200
Session 2 - M3 Setup and Administration

Warehouses, Locations, Numbering, and Users

1.5 hours
Objective

Find where a setup value lives before changing anything.

Scenario

Little Rock needs a cash desk and new bin locations before go-live. Find the current setup. Read-only.

Practice Tasks
1. Warehouses and bins
  1. Press Ctrl+R, type MMS005, and click OK. List the warehouse codes for Carrollton, Little Rock, and Lenexa.
  2. Press Ctrl+R, type MMS010. Filter on the Little Rock warehouse and note how many bin locations exist.
2. Numbering
  1. Press Ctrl+R, type CRS165, and click OK.
  2. Find the number series used for customer orders. Note the current number. Change nothing.
3. Users
  1. Press Ctrl+R, type MNS150, and click OK.
  2. Find your own user (KBICKERSTA) and note the company and division defaults.
Expected Outcomes
  • Warehouse codes and bin counts recorded.
  • Order number series found.
  • User defaults read in MNS150.
Sign-Off Checklist
  • I know where warehouses, bins, and number series live
  • I know how CRS022/CRS014 set default views
  • I build user access by role, not by copying
Knowledge Check
1. Bin locations are set up in:
  • MMS010 (correct)
  • MMS005
  • CRS165
  • OIS010
2. Order and invoice numbering is in:
  • CRS165 (correct)
  • CRS075
  • MWS410
  • OIS120
3. When giving a new user access you should:
  • Build the role for their job (correct)
  • Copy a power user
  • Give admin
  • Share your login
