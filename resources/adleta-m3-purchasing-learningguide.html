Session 1 - Purchasing / Procurement

Planned PO Release — PPS170

45 min
Objective

Open PPS170 and release a planned purchase order generated by MRP into a confirmed PO.

Scenario

MRP has generated planned orders for supplier AHF PRODUCTS (S900400) assigned to buyer ABURK. Open PPS170, review the planned order, and release it to a firm PO.

Practice Tasks
1. Open PPS170
  1. Press Ctrl+S to open Search and Start.
  2. Type PPS170 and select Planned Purchase Order. Open. Click OK.
  3. PPS170 opens showing a list sorted by Buyer, Supplier, PO type, and release date.
2. Review the planned orders in the list
  1. The list columns are: Buyer, Supplier, Supplier name, Otp (order type), Rel dt (release date), Plan qty, Net price.
  2. Use the Filter Options to narrow by Fac (facility = CAR) or Stat (status) if needed, then click Apply.
  3. Locate a line for buyer ABURK and supplier S900400 (AHF PRODUCTS).
  4. Review the planned quantity, release date, and order type before releasing.
3. Release the planned order
  1. Right-click the planned order line and review the available options.
  2. Select the release action to convert the planned order to a firm PO.
  3. M3 creates a PO in PPS200 and assigns a PO number (format: 200100xxx).
4. Verify the new PO in PPS200
  1. Press Ctrl+S, type PPS200, and open Purchase Order. Open.
  2. Find the new PO - it will show supplier S900400, buyer ABURK, order type B01, and warehouse CAR.
  3. Confirm the status and quantity match what was on the planned order.
Expected Outcomes
  • Planned order released and a new PO appears in PPS200.
  • PO linked to supplier S900400 (AHF PRODUCTS) with correct item and quantity.
  • MRP no longer shows the planned order - it is now a firm PO.
Exception Handling
No planned orders appear in PPS170
PPS170 shows orders for your buyer code. If the list is empty, MRP may not have generated orders yet or the buyer code filter is set to a different buyer. Check with Alan Burk.
The planned order quantity looks incorrect
Do not release it. Right-click and open the order detail to review the MRP parameters. Flag the issue to Alan Burk before releasing.
The supplier on the planned order is not the expected supplier
MRP assigns the preferred supplier. Confirm with Alan Burk whether to release as-is or change the supplier before releasing.
The new PO does not appear in PPS200 after releasing
Allow a minute for M3 to update. If it still does not appear, return to PPS170 to confirm the release completed without an error message.
Sign-Off Checklist
  • I can filter PPS170 to my buyer code
  • I review each planned order before releasing
  • I can release a planned order and find the new PO in PPS200
Knowledge Check
1. Planned POs in PPS170 come from:
  • The buyer typing them
  • M3's planning based on demand (correct)
  • The supplier
  • AP
2. After releasing, you check the new PO in:
  • APS100
  • PPS200 (correct)
  • CRS610
  • MWS410
3. A planned order's quantity looks wrong. You:
  • Release it anyway
  • Don't release it and ask Alan (correct)
  • Delete the item
  • Change the supplier master

Manual PO — Non-Stock / One-Time Purchase

60 min
Objective

Create a manual non-stock purchase order in PPS200 for a one-time exception item.

Scenario

A project needs a non-stocked item that will not go through MRP. Create a manual PO in PPS200 for supplier AHF PRODUCTS (S900400), warehouse CAR.

Practice Tasks
1. Open PPS200 and start a new PO
  1. Press Ctrl+S, type PPS200, and open Purchase Order. Open.
  2. Click the + (New) button in the toolbar to open a new PO header.
  3. Enter Supplier = S900400. M3 auto-fills the supplier name (AHF PRODUCTS) and default payment terms.
2. Enter the PO header details
  1. Confirm Order type = B01 or select the appropriate order type for this purchase.
  2. Set Warehouse = CAR (Carrollton).
  3. Enter the requested delivery date.
  4. Save the header - M3 assigns a PO number in the format 200100xxx.
3. Add the order line
  1. On the order lines panel, enter the item number (e.g., ARM51899031 or the correct item for this purchase).
  2. Enter the quantity and confirm the unit of measure (CT = cartons for most flooring items).
  3. Verify the unit price against the supplier quote - adjust if no price list entry exists.
  4. Save the line.
Expected Outcomes
  • Manual PO created in PPS200 with a system-assigned PO number.
  • PO linked to supplier S900400, warehouse CAR, order type B01.
  • Order line shows correct item, quantity, and price - ready for receiving.
Exception Handling
Supplier S900400 does not appear when you search
Search by the supplier number S900400, not by name. If it still does not appear, the supplier may be inactive - check status in CRS620 (should show 20-Approved).
The order type B01 is not available
Contact Alan Burk or IT. The order type must be active and assigned to your user role before it will appear.
No price pulls from the price list for the item
Enter the agreed price manually and note the source in the PO line reference field. Ask Alan Burk to set up the price list entry so future orders price automatically.
You save the PO but cannot find it in PPS200 afterward
Filter PPS200 by your buyer code (ABURK) or search by the PO number M3 assigned. Check that you are in company 100 (CMP100).
Sign-Off Checklist
  • I check the supplier is 20-Approved first
  • I can create a manual PO header and line
  • I check price against the quote and note manual prices
Knowledge Check
1. Supplier status needed to buy from them:
  • 10
  • 20-Approved (correct)
  • 90
  • Any
2. A supplier is missing in CRS620. You:
  • Create it
  • Contact Finance (correct)
  • Use another supplier
  • Leave the supplier blank
3. No price pulls on the PO line. You:
  • Leave it at zero
  • Enter the agreed price and note the source (correct)
  • Cancel the PO
  • Use last year's price

Receiving Goods — PPS300

60 min
Objective

Receive goods against a confirmed PO in PPS300 and confirm the receipt details.

Scenario

AHF PRODUCTS has delivered cartons of tile against an open PO. Open PPS300, enter the received quantities, and post the receipt.

Practice Tasks
1. Open PPS300 and locate the PO
  1. Press Ctrl+S, type PPS300, and open Purchase Order. Receive Goods.
  2. In the filter area, enter the PO number in the PO number field.
  3. Confirm Warehouse = CAR (Carrollton) is already populated - this defaults to your warehouse.
  4. Click Apply to display the PO lines.
2. Review PO lines before receiving
  1. The list shows columns: Ln (line), Sub, Item number, PO item name, Remain (remaining qty to receive), Recved qty, Com (complete), Location.
  2. Confirm the item number and PO item name match the physical delivery.
  3. Check the Remain column - this is the outstanding quantity not yet received.
  4. Verify the delivery note from AHF PRODUCTS matches the items and quantities shown.
3. Enter received quantity and post
  1. Select the PO line and enter the quantity actually received in the Recved qty field.
  2. Enter the delivery note number from the AHF PRODUCTS packing slip.
  3. If the delivery is complete, confirm the Com (complete) flag.
  4. Post the receipt - M3 updates inventory in warehouse CAR and creates the receipt transaction.
Expected Outcomes
  • Goods receipt posted against the PO in PPS300.
  • Inventory in warehouse CAR increases by the received quantity.
  • Receipt transaction created and the PO line Remain quantity decreases.
Exception Handling
PPS300 shows no lines after entering the PO number
Confirm the PO exists in PPS200 and has a status that allows receiving (not status 90 cancelled). Also confirm the warehouse filter shows CAR.
The received quantity is less than the PO quantity
Enter only what physically arrived. The Remain quantity stays open for the balance - do not mark the line complete. Follow up with AHF PRODUCTS on the short delivery.
The item on the delivery does not match the PO item name
Do not receive it. Stop and contact AHF PRODUCTS to confirm what was shipped. If it is the wrong item, reject the delivery.
PPS300 shows the receipt posted but inventory in CAR did not increase
Allow a few minutes for M3 to update. If inventory still does not reflect the receipt after 5 minutes, contact IT with the receipt transaction number.
Sign-Off Checklist
  • I can find a PO in PPS300 and check it against the packing slip
  • I enter only what arrived, with lot and delivery note
  • I handle short and over shipments correctly
  • I can see the received stock in MWS068
Knowledge Check
1. Receive only what:
  • Is on the PO
  • Is physically on the dock (correct)
  • The supplier invoiced
  • Purchasing expects
2. After a short receipt, the balance:
  • Is cancelled
  • Stays open in Remain (correct)
  • Goes to AP
  • Is written off
3. Where can you see the received lot by location?
  • MWS068 (correct)
  • CRS620
  • OIS100
  • GLS210

Changing a PO — Lines, Notes, and Cancelling

1 hour
Objective

Manage an existing PO in PPS200 - cancel a line, add a delivery note, and review PO status.

Scenario

An open PO with supplier S900400 (AHF PRODUCTS) needs one line cancelled and a delivery instruction note added.

Practice Tasks
1. Find the PO in PPS200
  1. Open PPS200 and search for the PO by PO number or filter by supplier S900400 and buyer ABURK.
  2. Click the PO number to open PPS201 (Purchase Order. Open Lines) and review the line detail.
  3. Identify the line to be cancelled and confirm its current status.
2. Cancel the PO line
  1. In PPS201, right-click the line to be cancelled.
  2. Review the available status change options.
  3. Select the cancel or close action - confirm M3 updates the line status.
  4. Note: A line that already has a receipt posted cannot be cancelled directly.
3. Add a note to the PO
  1. From the PO header, navigate to the Text or Notes option (check Actions or Options menu).
  2. Enter the delivery instruction note (e.g., Deliver to dock B - call ahead on 972-555-0100).
  3. Set the note type as appropriate (internal vs. external - external notes print on the PO).
  4. Save the note and confirm it is linked to the PO.
Expected Outcomes
  • Selected PO line status updated to cancelled.
  • Delivery note saved and linked to the PO header.
  • Remaining PO lines are unchanged.
Exception Handling
M3 will not let you cancel the PO line
The line may already have a receipt posted against it . A received line cannot be cancelled directly - contact Philip Jones.
The note type options are not clear
An Internal note is visible only in M3. An External note prints on the PO confirmation sent to AHF PRODUCTS. Use External for supplier delivery instructions.
You cancel the wrong line by mistake
If the cancellation can be reversed, do so immediately. If not, you will need to add a new line with the correct item and quantity. Notify Alan Burk.
The PO shows a status you have not seen before
Don't change a status you're unsure about. Ask Alan Burk.
Sign-Off Checklist
  • I can find and change PO lines
  • I know external vs internal notes
  • I call the supplier before cancelling
  • I close received lines instead of cancelling
Knowledge Check
1. A line already has a receipt. You:
  • Cancel it
  • Close the remainder instead (correct)
  • Delete the PO
  • Change the supplier
2. Delivery instructions for the supplier go in:
  • An external note (correct)
  • An internal note
  • The item master
  • Nowhere
3. Before cancelling a PO:
  • Call the supplier (correct)
  • Tell AR
  • Run MRP
  • Nothing

Supplier Records and Changing the Supplier on a PO

1 hour
Objective

Look up a supplier record in CRS620 and confirm the key fields used on purchase orders.

Scenario

Before creating a PO for a new supplier, verify their record in CRS620. Then confirm the same information pulls correctly to a PO in PPS200.

Practice Tasks
1. Open CRS620 and review the supplier record
  1. Press Ctrl+S, type CRS620, and open Supplier. Open.
  2. The list shows: Supplier number, Supplier name, Telephone no 1, Sts (status), Sgr (supplier group), Sta (state).
  3. Search for supplier S900400 by entering it in the Supplier filter field.
  4. Confirm Sts = 20-Approved. A supplier that is not 20-Approved cannot be used on new POs.
2. Review purchase and financial settings in CRS624
  1. From CRS620, right-click S900400 and navigate to the purchase and financial settings (CRS624).
  2. Confirm the buyer assigned to this supplier (should show ABURK for AHF PRODUCTS).
  3. Review payment terms and any other purchasing defaults.
  4. Note any supplier-specific settings that affect PO creation.
3. Confirm supplier data pulls to a PO
  1. Open PPS200 and click New to start a new PO.
  2. Enter Supplier = S900400 and confirm M3 auto-fills: supplier name (AHF PRODUCTS), payment terms, and buyer (ABURK).
  3. Do not save this test PO - press Escape to cancel without saving.
  4. Confirm the auto-filled values match what you saw in CRS620 and CRS624.
Expected Outcomes
  • Supplier S900400 confirmed as 20-Approved in CRS620.
  • Buyer ABURK and payment terms confirmed in CRS624.
  • PO creation auto-fills supplier data correctly from the supplier master.
Exception Handling
The supplier shows a status other than 20-Approved
Do not create a PO for an inactive or unapproved supplier. Contact Finance (Philip Jones) to reactivate. Do NOT create a new supplier record yourself.
The buyer assigned in CRS624 is wrong
The buyer on the supplier master controls which buyer sees planned orders in PPS170. Contact Alan Burk to have the buyer assignment corrected in CRS624.
You need a supplier that is not in CRS620 at all
New suppliers must be set up by Finance before any PO can be created. Provide the supplier name, address, and payment terms to Philip Jones and wait for the setup to be completed.
The supplier data on the PO does not match what is in CRS620
The PO pulls data at the time of creation. If the supplier master was updated after the PO was created, the PO header may need to be manually corrected.
Sign-Off Checklist
  • I can check supplier status, buyer, and terms
  • I know where supplier-item data and agreements live
  • I document and re-check prices when changing a supplier
Knowledge Check
1. Supplier buyer and payment terms are in:
  • CRS624 (correct)
  • OIS100
  • MMS001
  • GLS100
2. A new supplier is needed. Who sets it up?
  • Any buyer
  • Finance (correct)
  • The warehouse
  • The supplier
3. You can change the supplier on a PO:
  • Anytime
  • Only before anything is received (correct)
  • Only after invoicing
  • Never

Following a PO — Confirmations and History

45 min
Objective

Understand the full purchasing cycle in M3 from planned order to received goods.

Scenario

Walk through the complete purchasing cycle for a replenishment order: from MRP planned order in PPS170, to PO in PPS200, to receipt in PPS300.

Practice Tasks
1. Trace the cycle: PPS170 to PPS200
  1. Open PPS170 and identify a planned order for buyer ABURK and supplier S900400.
  2. Note the Plan qty, Rel dt (release date), and Otp (order type = B01).
  3. Open PPS200 and find an existing PO for S900400 with buyer ABURK - this is what a released planned order becomes.
  4. Compare the statuses on the planned order and the PO. Write down what each status number reads on screen. We are still confirming what each one means at Adleta.
2. Review a PO in detail
  1. In PPS200, click a PO number to open PPS201 (Purchase Order. Open Lines).
  2. Review the line detail: Line number, Status (Lst), Warehouse (CAR), Item number (e.g., ARM51899031), Order qty, U/M (CT = cartons).
  3. Scroll right to see additional fields - each column represents a key piece of the order.
3. Trace the cycle: PPS200 to PPS300
  1. Open PPS300 and enter the PO number of a PO that has been received.
  2. Review Recved qty: what has already been received.
  3. Compare Remain vs Recved qty. If Remain = 0, the PO line was fully received.
  4. Once received, AP can match the supplier invoice in APS100.
Expected Outcomes
  • You can trace a replenishment order from plan to receipt.
  • You know which program handles each stage: PPS170, PPS200, PPS250, PPS300.
  • You wrote down the status numbers you saw for confirmation.
Exception Handling
A PO is stuck at a status and not advancing
Status does not advance automatically in all cases. Some transitions require an action (e.g., a receipt must be posted to advance to status 50). Identify which step is missing.
PPS170 shows planned orders but none are releasing to PPS200
Planned orders require a manual release action. They do not auto-release. Alan Burk or the buyer must review and release each one in PPS170.
The PO status in PPS200 does not match what the warehouse says happened
PPS200 status reflects M3 transactions only. If goods were received physically but no receipt was posted in PPS300, the status will not match. The warehouse team must post the receipt in M3.
Sign-Off Checklist
  • I can find PO lines in PPS220
  • I can record a supplier confirmation in PPS250
  • I can trace a PO from plan to receipt
Knowledge Check
1. To find open PO lines fast, use:
  • PPS220 (correct)
  • OIS301
  • GLS210
  • MMS310
2. A supplier confirms new dates. Record it in:
  • PPS250 (correct)
  • PPS390
  • CRS610
  • OIS120
3. The PO cycle in order is:
  • PPS300 → PPS200 → PPS170
  • PPS170 → PPS200 → PPS250 → PPS300 (correct)
  • APS100 → PPS200
  • OIS100 → PPS300
